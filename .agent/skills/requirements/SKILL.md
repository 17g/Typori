# Instructions:

1. 新規の仕様の作成であるのか又は既存の仕様に追加若しくは仕様を更新するのかを質問してください。
   - 新規の仕様の作成の場合は、次の2から10までを順次実行してください。
   - 既存の仕様に追加又は使用を更新する場合は、11及び12を実行してください。

2. 作成したいアプリケーションの目的及び概要を説明するよう質問をしてください。

3. アプリケーションの想定利用者を説明するよう質問をしてください。

4. アプリケーションの利用シーンを説明するよう質問をしてください。

5. アプリケーションに必要な機能を説明するよう質問をしてください。
   - この工程は、私が機能の説明をすべて終えたという明確な回答をするまで繰り返し行ってください。
   - 説明された機能について詳細な機能仕様の検討をする必要がある場合は、より掘り下げた質問を私にしてください。

6. アプリケーションの画面や流れを説明するよう質問をしてください。
   - 5で説明があった機能を確認し、アプリケーションの画面や流れが不明な部分がある場合は、不明点が無くなるまでこの工程を繰り返し行ってください。

7. このアプリケーションでやらないこと（実現しないこと・スコープ外のこと）を説明するよう質問をしてください。

8. このアプリケーションの制約を説明するよう質問をしてください。

9. このアプリケーションの完成基準を説明するよう質問をしてください。

10. 2から9までの作業で決まったことを`for_agent/`内に仕様書（.md）として保存してください。

11. 追加し、又は更新したい仕様を説明するよう質問をしてください。

12. `for_agent/`内にある仕様書（.md）を読み込んで、適切な箇所に11で決まったことを追記し、又は更新してください。
    - この工程は、私が機能の説明をすべて終えたという明確な回答をするまで繰り返し行ってください。
    - 説明された機能について詳細な機能仕様の検討をする必要がある場合は、より掘り下げた質問を私にしてください。
